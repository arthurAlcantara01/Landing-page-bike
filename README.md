# Landing Page de Bicicletas

## Sobre a landing page

Uma landing page de bicicletas desenvolvida para apresentar produtos/serviços de forma clara, moderna e objetiva.
O projeto foi criado com foco em design responsivo, boa experiência do usuário e organização visual, funcionando perfeitamente em computadores, tablets e dispositivos móveis.

Este projeto foi desenvolvido para estudo e prática de desenvolvimento frontend, com base em conteúdos educacionais e adaptações próprias.

---

## Tecnologias utilizadas

- HTML5

- CSS3

- JavaScript

- GitHub (controle de versão)

---

## Características

- Layout moderno e minimalista

- Estrutura de landing page (Hero, seções informativas e contato)

- Design totalmente responsivo

- Código organizado e de fácil manutenção

- Foco em usabilidade e apresentação visual

---

## Aprendizados

- Estruturação de landing pages focadas em apresentação

- Boas práticas de HTML semântico

- Responsividade com CSS

- Organização de estilos e seções
